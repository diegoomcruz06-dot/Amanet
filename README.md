# Amanet Digital

Design-System und Web-Projekte von Amanet Digital, Wohlen AG.

- `CLAUDE.md` – verbindliches Design-Briefing (Farben, Typografie, Logo, Ton, Formate, Qualitätscheck)
- `assets/css/amanet.css` – Tokens und Komponenten als CSS
- `assets/logo/` – Logo mit Rahmen und Markenzeichen ohne Rahmen
- `styleguide.html` – Referenzseite aller Bausteine (im Browser öffnen)
